# zhongzhi-network-dabian · 中职网络设备讲课答辩技能

中职教师高级讲师职称评审"讲课答辩"的持久知识库与应答技能，面向《网络设备安装与调试（华为版）》教材。

**功能**：用户报出教材某个知识点（如"3.2 路由表""2.7 VLAN 功能""5.9 CHAP"），即可按河南省中职教师职称评审讲课答辩口径（答辩＝教育方针政策＋教育教学理论＋学科专业及相关知识，答题公式"观点→依据→结合自身→收尾"，每题 40—60 秒）自动生成面试答辩准备包。

**内容**
- 9 个模块 / 34 个任务 / 79 个知识点全覆盖，每个知识点含"核心概念 / 华为关键命令与配置步骤 / 教学要点 / 答辩角度"四字段
- 教育方针政策类 12 题 + 教育教学理论类 12 题 + 针对本节课追问 5 题 + 应答技巧（网络设备教学语境版）
- 考前必背 15 个核心词速记清单

**安装到 AI 助手**

```bash
npx skills add https://github.com/keweny416-debug/zhongzhi-network-dabian --skill zhongzhi-network-dabian
```

安装后，在对话中直接报教材知识点编号或名称即可触发。

**说明**：内容由教材目录骨架、华为 VRP 标准知识、官方核对页码及《高级讲师答辩常考点及参考答案》整理而成；教材独有实验数值与模块 8/9 页码标"待核"，政策表述以答辩时最新官方口径为准。
